# Lil Foots: Big Adventure — Level Design Philosophy
(Locked by Bude, Sept 17 2026. Original experience — no Mario/Nintendo assets, characters, levels, layouts, sounds, branding, or copyrighted designs.)

## Core Level Length
- Standard level: 2–4 min (first-time player). Advanced: 4–6. Boss: 3–6. Bonus/secret: 30s–2min.
- Never stretch to pad length. Density, variety, and fun first.

## Core Formula: every level follows TEACH → PLAY → DEVELOP → CHALLENGE → FINALE → REWARD
1. TEACH — introduce the primary mechanic safely, visual cues, no cheap punishment.
2. PLAY — use it naturally; basic enemies/obstacles/collectibles; build confidence.
3. DEVELOP — combine with earlier mechanics; complexity ramps; alternate routes + secrets open up.
4. CHALLENGE — strongest combination; difficulty from understanding + execution, not traps.
5. FINALE — a memorable sequence (chase, set piece, big challenge); feels different from the opening.
6. REWARD — satisfying ending; collectibles, progression, effects, story; reaching the goal means something.

## Level Density (per standard level)
- 3–5 major gameplay sections. 1 primary mechanic. 1–3 supporting mechanics.
- Multiple enemy encounters. Collectibles. ≥1 secret or alternate route. ≥1 memorable moment.
- Clear beginning and ending.
- Pacing: EASY → EASY → MODERATE → MODERATE → HARD → FINALE (sections are NOT equal difficulty).

## Checkpoints
- Every ~1–2 min. Never repeat a large section after dying. Fast restarts. Checkpoints = meaningful progress.

## Platforming
- Readable jumps; show landing areas before commitment; no blind jumps on normal routes.
- Vary distance/height; stationary + moving platforms; occasional verticality; environment as gameplay.
- Skilled movement rewarded, never required for basic completion.

## Enemies
- Introduce each enemy alone before combining with other threats. Recognizable behaviors.
- Placement drives movement decisions. Don't fill every screen. Mix combat + platforming. Skilled players can bypass.

## Collectibles
- Easy (main route) / Exploration (optional areas) / Difficult (advanced movement) / Hidden (observation).
- Never random placement.

## Secrets (≥1 per standard level)
Hidden rooms, alternate paths, breakable walls, hidden platforms, underground areas, vertical bonuses, risk/reward routes, challenge rooms. Reward curiosity.

## Player Flow
Alternate: running, jumping, platforming, enemies, exploration, collecting, safe beats, big challenges. Never one action for an extended stretch.

## Visual Communication
The player must understand the environment instantly.
