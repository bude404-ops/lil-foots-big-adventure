# Lil Foots: Big Adventure — Art Style Guide v0.1
(derived from Bude's two canon reference images — Sept 16 2026)

## Canon References
- bude-ref-01-lilfoots.jpg — green cartoon monkey, light blue bow, multicolored polarized sunglasses
- bude-ref-02-lilfoots.jpg — yellow construction hard hat with a paw print logo on the front

## Style Rules (extracted)
1. FLAT CARTOON — minimal gradients, clean solid fills, no painterly texture
2. BOLD ACCESSORY-DRIVEN DESIGN — each character/item defined by 1-2 big signature accessories (shades + bow, branded hard hat)
3. ONE COLOR POP PER ACCESSORY — light blue bow, multicolor lenses, safety yellow hat; accessories pop against the character's base color
4. SIMPLE BACKGROUND — solid flat beige/natural tone, subject is the star
5. THICK OUTLINES — cartoon linework weight, chunky friendly shapes
6. LOGO LANGUAGE — the paw print = the brand mark of the world (hat branding); reusable across items/props

## Character DNA (working read)
- Hero archetype: playful monkey crew — bold, confident, accessory-forward
- Worker archetype: construction hard hat + paw print logo = the fixer/builder character or costume
- Props can carry the paw print brand as an in-world logo system
